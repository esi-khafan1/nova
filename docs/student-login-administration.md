# Super-admin student login administration

The student-login page is available only to a super administrator with a verified account email. It creates a student login, changes a student password, manually confirms a student phone, or combines the last two operations. These actions do not assign a counselor or activate paid services. A new student starts with an empty profile name and can fill it in independently on their panel.

The server route invokes the `superadmin-student-login` Edge Function using the administrator's session. That function revalidates the user, super-admin capability, and verified email. A fresh eight-digit code is emailed from `security@auth.nova-academy.ir`, using the Edge Function secret `NOVA_ADMIN_OTP_RESEND_API_KEY`. No secret or email code belongs in Git or browser-accessible environment variables. Existing Supabase Auth email templates and SMTP settings are unchanged.

Migration 114 provides the private challenge/audit table and service-only RPCs. A challenge is bound to the actor, session, account phone and operation. It expires after five minutes, allows at most five incorrect attempts, and is consumed before mutation. A keyed HMAC, not the code or password, is stored. The database rate-limits requests and guards changes to the student's role and phone during an Auth Admin operation. An uncertain Auth outcome is logged as unknown; check the target account before retrying. Manual confirmation is recorded as such in the private operation audit, and does not prove that the student received an SMS.

Deploy the migration and the Edge Function before deploying the web UI. The secret must be configured separately in Supabase. Run local tests `node tests/superadmin-student-login-sql.test.cjs`, `node tests/superadmin-student-login-handler.test.mjs`, and `node tests/student-name-only.test.cjs`. These use synthetic data and mock mail/Auth providers; they do not establish real-world email deliverability or the behavior of the deployed Auth service. A real-account or real-email test requires explicit authorization and should use a controlled test account.
