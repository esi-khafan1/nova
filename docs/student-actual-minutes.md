# Actual minutes in student plan boxes

Students may enter non-`practice_tests` duration in one `HH:MM` field (for example `01:30`, accepted range `00:01`–`24:00`); Persian and Arabic numerals are accepted and normalized on blur. The value is stored as 1–1440 whole minutes. `practice_tests` keeps its separate optional numeric count (1–5000). Checking «انجام داده‌ام» with either field empty marks the whole planned duration or test target complete. NULL remains stored to distinguish an inferred goal from an actual entered amount. An already checked box can be edited by changing or clearing its value and leaving the field. Unchecking removes the recorded progress. Future boxes and counselor read-only views are unchanged. No SMS or exam submission is involved.

Migration 086 adds nullable `completed_minutes` to the existing completions table and a four-argument progress RPC. The old three-argument RPC remains available during rollout. The new RPC invokes the old student/active/published/own-plan/date validation in the same transaction, checks the activity-specific field, and preserves `checked_at` on edits. It uses an explicit authenticated EXECUTE grant; it creates no new public table. The student paged dashboard RPC and counselor report read include the new value. Migration 086 was applied and verified on the connected production Supabase project: column exists, authenticated can execute the new RPC, anonymous cannot, the dashboard projects minutes and no recorded minutes exist yet. Deploy the application after the migration; the application was not deployed by this commit.

Migration 087 updates only the four-argument progress RPC to accept NULL amounts while preserving own-student, active, published, date, value-range and first-tick guards. Migration 087 was applied and its authenticated/anonymous privileges, optional bounds and first-tick preservation were verified on the connected production Supabase project; old app builds keep using the unchanged three-argument RPC. The application deployment remains unverified. Previously completed non-test boxes have `completed_minutes = null`; they stay checked and reports use planned duration as an **inferred full amount**, never display it as entered actual time. Similarly, a checked test box without an entered count uses the plan target for fulfillment and totals, with a visible inferred-value label. If a legacy test box has no target, the checked box is complete but no count is invented. For new non-test boxes with a value, reports and counselor hours use actual minutes; for tests with a value they continue to estimate time from the completed/target test ratio. Fulfillment is capped at 100% even if actual study exceeds the planned duration, while the recorded time remains uncapped. The student's printable plan still has only planned activities and no progress input or actual minutes.

No production account or SMS needs to be used to test this feature.
