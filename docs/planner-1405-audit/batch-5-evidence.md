## Method and ground truth

- Fingerprint per book: `sha256sum` of the local PDF, page count from PyMuPDF
  (`pdfinfo` is not installed in this VM), and the imprint page inside the PDF
  (book code + چاپ ۱۴۰۵). 9 of 10 local SHA-256 values match the SHA documented
  for that book in `docs/planner-topic-sources.md`; `motaleat-ejtemai-9-907-1405.pdf`
  has no documented SHA and its local SHA is documented below.
- Offset (PDF page → printed page) determined from printed footers on many pages
  per book (counts in each section), cross-checked against the imprint page, the
  front table of contents, and lesson starts in the running text. The book text
  and printed numbers are the authority, not the TOC.
- Existing seed state was established by applying migrations 128–230 in PGlite
  (all applied, 0 failures; 20,702 rows in `private.planner_topic_bank`). Per-book
  diffs below are against that state, not against the migration files alone.
- Positions for new rows are ≥ 3000 in every chapter. Verified from the applied
  bank: no prior row in any batch-5 chapter uses a position ≥ 3000 (maxima are
  400 for جامعه‌شناسی ۱, 1009 for جغرافیای ایران, 2007 for جغرافیا ۳, 2003 for
  جغرافیا ۲, 651 for کار و فناوری, 746 for کتاب کار زبان, 703 for منطق, 692 for
  مدیریت خانواده, 2 for مطالعات اجتماعی), so no collision is possible; the `v235`
  id formula also makes every new id distinct from all prior rows.
- Pattern B (guarded page-fill) applies to eight مطالعات اجتماعی ۹ rows only:
  the migration-151 whole-lesson rows, whose v1 ids were verified to match the
  stored ids exactly (all revision 1, NULL pages) before filling.
- Test: `tests/planner-audit-batch-5-1405.test.cjs` — **PASS** (see Test results).
