### How the offset was determined

Printed page numbers were read from the footers of many pages of each
book and matched against PDF page numbers; the modal difference is the
offset. Counts of footer confirmations: 51: 68 (pdf pp. 5–127); 52: 83;
53: 73; 54: 108 (pdf pp. 1–111); 58: 158 (printed max 176 at pdf p.184);
59: 122 (pdf pp. 10–144); 60: 189 (pdf pp. 4–208). For 55/56/57 the text
layer has no extractable bottom digit blocks, so the offset was confirmed
manually on the running heads/footers: 55: pdf pp. 21→21, 31→31, 41→41,
61→61, 81→81, 91→91 (offset 0); 56: pdf pp. 41→41, 51→51, 61→61, 71→71,
81→81, 91→91 (offset 0); 57: pdf pp. 21→20, 31→30, …, 121→120 (offset −1;
TOC نیایش 122, منابع 123). Footer scans also picked up in-page exercise
numbers (e.g. offsets +9/+18 in the نگارش books); those are not footers
and were ignored — the modal offset above is the true one.

### How coverage was verified

1. The seed bank was dumped from a PGlite run of migrations 128–230 in
   order (no migration failed): **2068 rows** for the 10 subjects.
2. For each book, the union of seed ranges was computed; every printed
   page inside the covered span that no row covers was inspected page by
   page in the extracted PDF text.
3. The table of contents of each book was compared with the seed starts;
   **all TOC entries match seed starts exactly** (see per-book sections).
4. Boundaries and flagged rows were checked by reading the actual page
   text (headings, exercises, activities).

**Automated title-word matching was discarded as a verification method.**
Persian PDF text has vocalisation diacritics, ZWNJ/space variation, and
نگارش ۹ is a scanned/small PDF whose headings are images. Verification
rests on TOC + page-text reads + coverage analysis, as in batches 1–3.

blank pages, منابع / کتابنامه, نظرسنجی, cover/imprint pages. This is the
batches 1–2 precedent; migration 228's own sources note says the same
for نگارش ۱۲ («منابع» p.106 and the blank p.107 are not exercise rows).

**ستایش / نیایش — a recorded cross-family inconsistency.** ستایش and
نیایش get rows **only in the نگارش family**: migration 220 added ستایش
12 and نیایش 108 for نگارش ۹, and migration 228 added «پیوست — نیایش»

seeds never treated ستایش/نیایش as rows, and batches 1–2 leave front/back
matter without rows. Adding ستایش/نیایش rows for those families in this
batch would be inconsistent scope creep, so they were not added there —
but the inconsistency is recorded here rather than papered over. If a
later batch decides ستایش/نیایش are rows everywhere, the missing ones
